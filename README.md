# Any.do

Connect your Any.do account to work with personal task lists, workspace boards and sections, subtasks, reminders, and connected calendars.

## What you can do

- Find tasks by title, date range, list, workspace, board, or section
- Create personal tasks, workspace tasks, subtasks, lists, and boards
- Set one-time and recurring reminders
- View events from your connected calendars
- Review task and calendar edits before they are applied

## Sign-in

An Any.do account is required. The first time the agent uses an Any.do tool, Antigravity opens a browser window so you can sign in to Any.do. No API key is needed.

## Example prompts

- "Show my Any.do lists."
- "Find my tasks due this week."
- "Show my calendar events for tomorrow."
